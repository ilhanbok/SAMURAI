Segment Anything Model Utilized for Radiomic Analysis of Images

Browser front-end for the SAMURAI pipeline. The Python back-end is the same one the command-line scripts use — SAM2 video propagation over a NIfTI slice stack — with the matplotlib/Qt windows replaced by these pages.

Mode (i) · Manual selection

Pick a plane and slice, click intra-lesional (fg) and extra-lesional (bg) points or drag a bounding box, watch the prediction likelihood mask update, then propagate through the whole volume and edit the result.

Adjunct_SAM_lesion_threshAndFilter_wrapper_01232025.py

Mode (ii) · Threshold lesion finding

Threshold a RAW or QSM volume, label connected components, then walk the candidate list: inspect each one, approve or skip it, add corrective points and segment it into its own mask file.

thresholdSAM_01062025.py

Utilities

MERGE, ZERO, DUPLICATE, IRV and VOLUME — the post-segmentation curation toolkit, as web forms.
